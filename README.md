# Zombie House Clearer

Proyecto base en Godot 4 para un juego 2D tipo "soldado entra a casas, mata zombies y salva ciudadanos".

## Requisitos
- Godot 4.3+
- Exportador Web (HTML5) para publicar en una página web

## Cómo abrir
1. Abre Godot 4.
2. Importa esta carpeta como proyecto.
3. Ejecuta la escena principal.

## Cómo exportar a web
1. En Godot: Project > Export
2. Agrega el preset Web
3. Configura la exportación HTML5
4. Genera el paquete
5. Sube los archivos a tu hosting web

## Controles
- Mover: teclado A/D o joystick táctil
- Disparar: espacio o botón "Disparar"
- Apuntar: flechas arriba/abajo o botón "Apuntar"

## Sistema incluido
- Pantalla principal
- Tienda con armas y aliados
- Monedas
- Personaje con movimiento horizontal
- Zombies
- Civilians a rescatar
- Armas/bolas
- Compatibilidad para navegador web
